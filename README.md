# Bardia

An original single-player saga-strategy game set in an invented, Norse-inspired world: rule a hall, muster a war-band, sail or march out, trade, raid, fight battles on land and at sea, and found a dynasty.

Work in progress. All art, sound and music are placeholders drawn or generated by the program.

## Play it

On Windows, double-click `Play Bardia.cmd`. It builds the game and opens it in your browser.

Or from a terminal:

```
cd game
npm install
npm run dev
```

`HOW_TO_TEST.md` walks through what is playable and what is not built yet.

## For developers

The code is in `game/` (TypeScript, React, PixiJS, Vite). `game/ARCHITECTURE.md` is the engineering guide: layers, the module pattern, determinism rules, testing, and the menu and scene rules.

```
npm run typecheck
npx vitest run
npm run sim -- --days 365 --save-check
npx playwright test
```
